## 기능 소개

### 알림 시스템 구조
- Redis ZSet을 활용한 이벤트 발행 기반 알림 시스템
- 주문 데이터 → Redis → 알림 발송
- 주문 상태 변경, 리뷰 등록 등 푸시 알림

### 홈 피드 & 가게 검색
- 주변 가게의 띱박스(할인 음식 세트) 탐색
- 키워드 검색, 픽업 가능/거리/추가 할인 필터링
- 할인율 및 원가/할인가 표시

### 띱박스 주문 & 결제
- 마감 임박 음식을 할인된 가격에 구매
- Toss Payments 결제 연동

### 실시간 라이브 쇼핑
- OpenVidu 기반 실시간 스트리밍
- 사업자가 라이브로 띱박스 소개
- 시청자 수, 방송 시작 시간 표시
- 가게에서 언제든 간편하게 광고 가능
- 방송 미리보기: 카메라와 마이크를 확인하고 방송 시작
- 스트림에 성공적으로 연결되면 라이브 시작

### 주문 관리 (사업자)
![image_orders](https://i.imgur.com/Nekzm65.png)
- 주문 현황 실시간 확인
- 주문 확정, 픽업 완료 상태 관리
- 픽업 예상 시간 설정
- 주문번호, 고객 ID, 상품명, 수량, 금액, 주문일시, 픽업시간 조회

### 사업자 대시보드
![image_dashboard](https://i.imgur.com/8Cwrcu6.gif)
- 매장 운영 현황 한눈에 확인
- 오늘 총 매출, 총 주문 수, 평균 주문 금액, 월간 누적 매출
- 대기 중인 주문 / 픽업 대기 현황
- 띱박스 현황 (운영 중, 남은 재고, 일일 등록, 전체 띱박스)

### 매출 분석
![image_analytics](https://i.imgur.com/a6lA5Sh.png)
- 기간별 총 매출, 총 주문 수, 평균 주문 금액, 분석 지표
- 인기 상품 분석 (상품별/제품별 판매 비중) - 도넛 차트
- 할인율별 판매 현황 차트 - 막대 그래프
- 분석 기간 선택 가능 (예: 5월 17일 ~ 8월 17일)

### 가게 등록 (온보딩)
- 8단계 가게 등록 프로세스
- 기본 정보 (가게명, 사업자등록번호)
- 진행 상황 프로그레스 바 표시
- 사업자 정보, 가게 위치, 주요 메뉴 입력

### 매장 알림
![image_notification](https://i.imgur.com/Dg2jcZ8.png)
- Firebase FCM 기반 실시간 알림
- 매장에 온 알림 내역 확인
- 리뷰 등록, 주문 상태 변경 알림
- 타입, 제목, 발송일 목록 표시

### HTTP 모니터링
![image_monitoring](https://i.imgur.com/Om0GeFE.png)
- Grafana 대시보드로 Request Count 모니터링
- Response Time 분석 (Mean, Max, Min)
